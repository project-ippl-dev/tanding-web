## Running Dev Server

1. Make sure you have Node installed. If you haven't, get your preferred installer [here](https://nodejs.org/en/download).
2. Install packages by running the command below.
```bash
npm install
```
3. Run the development server:
```bash
npm run dev
```
4. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
